
## Descripción:

Este proyecto fue desarrollado con Python y tiene como objetivo comparar el funcionamiento y rendimiento de dos algoritmos de búsqueda:

- Secuencial
- Binaria

El programa crea una matriz de 1,000,000 de elementos y permite al usuario ingresar un número para buscarlo utilizando ambos métodos.

El programa muestra:

- Si el número fue encontrado
- La posición del número
- La cantidad de pasos realizados
- El tiempo de ejecución de cada algoritmo

## Instrucciones:

Para ejecutar el código se necesita:

1. Tener Python 3.3 o superior.
2. Clonar el repositorio.
3. Abrir el proyecto en Visual Studio Code.
4. Ejecutar el programa e ingresar el número que desea buscar.

## Pre-requisitos:

- Python 3.3 o superior

## Explicación:

Se pudo observar que la búsqueda secuencial tarda más tiempo, ya que revisa los elementos uno por uno hasta encontrar el número. En cambio, la búsqueda binaria es más rápida porque divide el arreglo en mitades, reduciendo la cantidad de pasos necesarios.
